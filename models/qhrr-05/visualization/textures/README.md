# Metal texture provenance

The default metal uses **ambientCG Metal009**, authored by Lennart Demes and provided under [CC0 1.0](https://docs.ambientcg.com/license/).

- Asset: https://ambientcg.com/view?id=Metal009
- Source: `Metal009_4K-PNG.zip` (4096×4096 Color/Roughness maps).
- Original archive and unused source channels stay in ignored `.cache/materials/`.
- Runtime `brushed_metal_color.png` preserves subtle brushing but remaps albedo to a neutral, bright metal.
- Runtime `brushed_metal_roughness.png` keeps the source grain while bounding roughness to prevent coarse stripes.
- `brushed_metal.json` records source/archive/output SHA256 and the 80mm projected tile scale.

```bash
python3 tools/prepare_metal_materials.py --download  # First preparation, explicitly downloads.
python3 tools/prepare_metal_materials.py             # Rebuild from verified cached archive.
```

The script requires Pillow. The application reads the prepared PNG files offline. A high-resolution normal or displacement map is not applied to the metal because the CAD lacks authored UV/tangent data; visible brushing comes from roughness and the anisotropic PBR shader instead. Existing procedural floor/non-metal maps are generated by `tools/generate_pbr_textures.py`.
