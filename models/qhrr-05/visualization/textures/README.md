# Metal texture provenance

The silver and graphite metal roughness maps use **ambientCG Metal009**, authored by Lennart Demes and provided under [CC0 1.0](https://docs.ambientcg.com/license/).

- Asset: https://ambientcg.com/view?id=Metal009
- Source: `Metal009_4K-PNG.zip` (4096×4096 Roughness map).
- Original archive and unused source channels stay in ignored `.cache/materials/`.
- Base color is constant: a flat white 16×16 MJCF texture only enables projected UV scaling. No photographed color pattern is multiplied into the metal albedo.
- `brushed_metal_roughness.png`: effective linear roughness 0.322–0.380, mean 0.349.
- `graphite_metal_roughness.png`: effective linear roughness 0.357–0.404, mean 0.380.
- Both use `roughness=1`, projected `texrepeat=10` (200mm tile), and a 0.7px source blur to reduce fine aliasing.
- Black anodized housing is separate: no textures, roughness 0.42, metallic 0.85, isotropic reflection.
- `brushed_metal.json` records source/archive/output SHA256, measured ranges, and scale.

```bash
python3 tools/prepare_metal_materials.py --download  # First preparation, explicitly downloads.
python3 tools/prepare_metal_materials.py             # Rebuild from verified cached archive.
```

The script requires Pillow. The application reads the prepared PNG files offline. A high-resolution normal or displacement map is not applied to the metal because the CAD lacks authored UV/tangent data; fine brushing comes from roughness and weak anisotropic reflection on full-metal alloys instead. Floor maps are generated by `tools/generate_pbr_textures.py`. Legacy color/anodize/aluminum/floor-roughness files remain for comparison but are not referenced by the active materials.
