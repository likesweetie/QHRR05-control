접수와 적용을 구분합니다. 응답을 확인할 수 없으면 UNKNOWN으로 남깁니다.

이 데모의 명령 정책
  • Arm: DISABLED → ENABLING → DAMPING.
    Run: DAMPING → NORMAL.
  • Damping: NORMAL → DAMPING.
    Reset: ESTOP → DISABLED.
  • 일반 명령은 적용 직전에 TX 허용, 응답, 모든 필수 피드백을 다시 확인합니다. 활성 준비 중 조건을 잃으면 합성 모델은 DISABLED로 복귀합니다.
  • ESTOP은 진행 중인 일반 요청보다 우선합니다. 응답 복구만으로 정지 요청 래치를 해제하지 않습니다.
  • 적용은 합성 제어기 전이 확인입니다. 실제 모터의 물리적 정지 완료를 뜻하지 않습니다.
